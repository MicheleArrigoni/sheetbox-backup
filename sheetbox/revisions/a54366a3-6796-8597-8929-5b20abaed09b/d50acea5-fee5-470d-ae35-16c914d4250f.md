# PyTorch — cheatsheet

## Setup e device

Installa la build adatta al tuo sistema dal [selettore ufficiale](https://pytorch.org/get-started/locally/). Gli esempi usano solo `torch`; il training usa dati sintetici e non scarica dataset.

```python
import torch
from torch import nn
from torch.utils.data import DataLoader, TensorDataset

torch.manual_seed(42)
device = torch.device(
    "cuda" if torch.cuda.is_available()
    else "mps" if torch.backends.mps.is_available()
    else "cpu"
)
print(torch.__version__, device)
```

## Tensori e operazioni

```python
x = torch.tensor([[1., 2., 3.], [4., 5., 6.]])  # (2, 3)
zeros = torch.zeros(2, 3)
noise = torch.randn(2, 3)
indices = torch.arange(6)
print(x.shape, x.dtype, x.device)

x[:, 0]                      # prima colonna: (2,)
x.reshape(3, 2)              # cambia forma, stesso numero di elementi
x.unsqueeze(0)              # (1, 2, 3)
x.transpose(0, 1)            # (3, 2)
x + torch.tensor([1., 0., -1.])  # broadcasting
x * x                       # prodotto elemento per elemento
x @ x.T                     # prodotto matriciale: (2, 2)
x.mean(dim=0)                # media sulle righe: (3,)
x.sum(dim=1, keepdim=True)   # somma sulle colonne: (2, 1)
torch.cat([x, x], dim=0)     # (4, 3), dimensione esistente
torch.stack([x, x], dim=0)   # (2, 2, 3), nuova dimensione
x.to(device=device, dtype=torch.float32)
```

`to()` va assegnato quando serve il tensore convertito. `reshape()` può restituire una vista o una copia; `view()` richiede stride compatibili. Il broadcasting confronta le dimensioni da destra: devono essere uguali oppure una deve valere 1.

## Autograd

```python
w = torch.tensor([2., -1.], requires_grad=True)
loss = w.square().sum()  # scalare
loss.backward()
print(w.grad)           # tensor([4., -2.])
w.grad = None           # azzera prima del prossimo accumulo
detached = w.detach()   # senza grafo; condivide lo storage
independent = w.detach().clone()
```

`backward()` accumula i gradienti. Per una loss non scalare fornisci un gradiente oppure applica prima una riduzione. `detach()` interrompe il collegamento al grafo per quel risultato.

## Training completo: classificazione

Esegui prima il blocco di setup. Input `(N, 12)`, tre classi, target interi `(N,)`.

```python
features = torch.randn(240, 12)
labels = (features[:, :3] @ torch.tensor([
    [2., -1., 0.], [0., 2., -1.], [-1., 0., 2.]
])).argmax(dim=1)
loader = DataLoader(TensorDataset(features, labels),
                    batch_size=32, shuffle=True, num_workers=0)

model = nn.Sequential(
    nn.Linear(12, 24),
    nn.ReLU(),
    nn.Linear(24, 3),
).to(device)
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)

for epoch in range(5):
    model.train()
    total_loss = 0.0
    for xb, yb in loader:
        xb, yb = xb.to(device), yb.to(device)
        optimizer.zero_grad(set_to_none=True)
        logits = model(xb)
        loss = loss_fn(logits, yb)
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * xb.size(0)
    print(epoch + 1, total_loss / len(loader.dataset))
```

Per `CrossEntropyLoss` con indici di classe: passa logits `(N, C)` e target `torch.long` `(N,)` nell'intervallo `[0, C)`. Non applicare softmax prima della loss. L'esempio serve a mostrare il flusso; per valutare la generalizzazione usa dati di validazione separati.

## Inferenza

```python
model.eval()
with torch.inference_mode():
    logits = model(features[:8].to(device))
    probabilities = logits.softmax(dim=-1)
    predictions = logits.argmax(dim=-1)
print(predictions.cpu().tolist())
```

`eval()` cambia il comportamento di layer come Dropout e BatchNorm; il contesto disabilita la registrazione autograd. Servono entrambi per la normale inferenza. Per riutilizzare risultati in calcoli che richiedono autograd, considera `torch.no_grad()` al posto di `inference_mode()`.

## Salvare e ricaricare i pesi

```python
torch.save(model.state_dict(), "weights.pt")

restored = nn.Sequential(
    nn.Linear(12, 24), nn.ReLU(), nn.Linear(24, 3)
).to(device)
state = torch.load("weights.pt", map_location=device, weights_only=True)
restored.load_state_dict(state)
restored.eval()
```

Ricrea la stessa architettura prima di caricare lo `state_dict`. Per riprendere il training conserva anche `optimizer.state_dict()` ed epoca, poi ripristinali e usa `train()`. Carica file di provenienza fidata: `weights_only=True` limita la deserializzazione, senza rendere sicuro qualsiasi file.

## Diagnostica rapida

| Problema | Controllo |
| --- | --- |
| Shape incompatibili | Stampa le shape prima del layer; `Linear` trasforma l'ultima dimensione. |
| Device diversi | Sposta modello e batch sullo stesso device prima del forward. |
| Target con dtype errato | Per classificazione con indici usa `yb.long()`. |
| Gradienti inattesi | Controlla `zero_grad()`, `requires_grad` e possibili `detach()`. |
| Memoria in crescita | Per log conserva `loss.item()`, evitando di trattenere il grafo. |
| Conversione NumPy | Con NumPy installato: `tensor.detach().cpu().numpy()`. |
