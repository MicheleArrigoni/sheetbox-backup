## 1. Environment and help

```sh
python --version
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install numpy matplotlib
python -m pip freeze > requirements.txt
python -m pip install -r requirements.txt
python -m pip check
```

Choose the appropriate PyTorch build using its [installation selector](https://pytorch.org/get-started/locally/). `python -m pip` targets that interpreter. Record Python and package versions for reproducibility; `freeze` records the current environment, including transitive dependencies.

```python
import sys
print(sys.version)

```

## 2. Values, operators, and truth

| Concept | Syntax / behavior |
| --- | --- |
| Scalar types | `int`, `float`, `complex`, `bool`, `str`, `bytes`, `None` |
| Arithmetic | `+ - * / // % **`; `/` is true division; `//` floors |
| Comparisons | `== != < <= > >=`; chained: `0 <= x < 10` |
| Identity | `x is None`; `is` tests object identity, not value equality |
| Logic | `and`, `or`, `not`; first two short-circuit and return operands |
| Membership | `x in items`, `key in mapping` |
| False values | `False`, `None`, numeric zero, empty containers/strings |
| Conversions | `int('12')`, `float('1.5')`, `str(12)`, `list(range(3))` |

```python
import math
x = 7
assert x // 3 == 2 and -7 // 3 == -3
assert divmod(7, 3) == (2, 1)
assert math.isclose(0.1 + 0.2, 0.3, rel_tol=1e-9, abs_tol=1e-12)
a, b = 1, 2
a, b = b, a
first, *middle, last = range(5)
```

Integers have arbitrary precision; floating-point arithmetic rounds. Use `math.isclose` with tolerances appropriate to the problem. `/` and `**` have different precedence from unary minus: `-2**2 == -4`.

## 3. Collections and mutation

| Type | Properties | Common operations |
| --- | --- | --- |
| `list` | Ordered, mutable sequence | `append`, `extend`, `insert`, `pop`, `remove`, `sort` |
| `tuple` | Immutable sequence | `(1,)` for one item; unpacking |
| `dict` | Mutable key/value map; insertion order | `get`, `items`, `keys`, `values`, `update`, `pop` |
| `set` | Unique hashable elements; no positional order | `add`, `discard`, union `\|`, intersection `&`, difference `-` |
| `frozenset` | Immutable set | Usable as a dictionary key |

```python
items = [10, 20, 30, 40]
assert items[-1] == 40
assert items[1:3] == [20, 30]      # stop excluded
assert items[::-1] == [40, 30, 20, 10]
items.append(50)                   # mutates; returns None
ordered = sorted(items, reverse=True)  # new list
counts = {'red': 2}
counts['blue'] = counts.get('blue', 0) + 1
for color, count in counts.items():
    print(color, count)
unique = set([1, 1, 2])
empty_set = set()                  # {} is an empty dict
```

Dictionary keys and set elements must be hashable. A tuple containing a list is not hashable. `list.copy()` and slicing make shallow copies: nested objects remain shared. Assignment binds a name to an object; it does not copy it.

```python
from copy import deepcopy
rows = [[0] for _ in range(3)]     # independent rows
alias = rows
shallow = rows.copy()
deep = deepcopy(rows)
rows[0][0] = 9
assert alias is rows and shallow[0][0] == 9 and deep[0][0] == 0
```

Avoid `[[0] * width] * height` when rows must be independent. [Data structures](https://docs.python.org/3/tutorial/datastructures.html).

## 4. Strings and formatting

```python
text = '  alpha,beta  '
parts = text.strip().split(',')
assert '|'.join(parts) == 'alpha|beta'
assert 'report.csv'.endswith('.csv')
value = 12.3456
print(f'value={value:.2f}, fraction={0.125:.1%}, index={7:04d}')
payload = 'caffè'.encode('utf-8')  # str -> bytes
assert payload.decode('utf-8') == 'caffè'
```

Strings are immutable Unicode sequences; `replace`, `strip`, and `lower` return new strings. Use `casefold()` for broad Unicode caseless matching. Raw strings such as `r'\d+'` are useful for regexes; they cannot end with a single backslash. [Text and formatting](https://docs.python.org/3/tutorial/inputoutput.html).

## 5. Control flow, comprehensions, and iteration

```python
values = [-2, 0, 3, 5]
squares = [v * v for v in values if v > 0]
lookup = {v: v * v for v in values}
remainders = {v % 3 for v in values}
total = sum(v * v for v in values)  # generator; no intermediate list
for index, value in enumerate(values, start=1):
    if value < 0:
        continue
    if value > 4:
        break
    print(index, value)
else:
    print('loop finished without break')
for name, score in zip(['a', 'b'], [2, 3], strict=True):
    print(name, score)
status = 'positive' if total > 0 else 'zero'

def countdown(n):
    while n > 0:
        yield n
        n -= 1

assert list(countdown(3)) == [3, 2, 1]
```

`range(start, stop, step)` excludes stop. `zip` normally stops at the shortest input; `strict=True` detects unequal lengths. Iterators and generators are consumed as you iterate. `any` and `all` short-circuit; `all([])` is `True`, `any([])` is `False`. Avoid changing a collection's size during iteration. [Control flow](https://docs.python.org/3/tutorial/controlflow.html).

## 6. Functions, scope, and typing

```python
def scale(value: float, /, factor: float = 2.0, *, offset: float = 0.0) -> float:
    return value * factor + offset

assert scale(3, factor=4, offset=1) == 13

def collect(value, bucket=None):
    if bucket is None:             # defaults are evaluated once at definition
        bucket = []
    bucket.append(value)
    return bucket

def forward(*args, **kwargs):
    return scale(*args, **kwargs)

pairs = [('b', 2), ('a', 1)]
assert sorted(pairs, key=lambda pair: pair[1])[0] == ('a', 1)
```

Before `/`: positional-only. After `*`: keyword-only. `*args` gathers positional arguments; `**kwargs` gathers keywords; the same syntax unpacks arguments at a call. A missing `return` returns `None`. Lookup follows local, enclosing, global, built-in scopes; use `nonlocal` or `global` for explicit rebinding. Type hints are not automatic runtime validation.

## 7. Classes and dataclasses

```python
from dataclasses import dataclass, field

@dataclass
class Run:
    name: str
    scores: list[float] = field(default_factory=list)

    def add(self, score: float) -> None:
        self.scores.append(score)

    @property
    def best(self) -> float | None:
        return max(self.scores, default=None)

run = Run('baseline')
run.add(0.9)
assert run.best == 0.9
```

Instance methods receive `self`; `super().__init__()` initializes a base class. Define mutable per-instance data inside `__init__` or with `default_factory`. Class attributes are shared. `__repr__`, `__len__`, `__iter__`, and `__enter__/__exit__` implement common protocols. `@staticmethod` receives no implicit instance; `@classmethod` receives the class. [Classes](https://docs.python.org/3/tutorial/classes.html).

## 8. Exceptions, resources, and files

```python
import json
from pathlib import Path
from tempfile import TemporaryDirectory

try:
    number = int('12')
except ValueError as exc:
    raise ValueError('Expected an integer') from exc
else:
    assert number == 12
finally:
    pass                           # executes on leaving the try statement

with TemporaryDirectory() as directory:
    path = Path(directory) / 'run.json'
    path.write_text(json.dumps({'score': 0.9}, indent=2), encoding='utf-8')
    result = json.loads(path.read_text(encoding='utf-8'))
    assert result['score'] == 0.9
    with path.open(encoding='utf-8') as stream:
        first_line = stream.readline()
```

Catch specific exceptions. `raise` rethrows inside a handler; `raise ... from exc` chains causes. `with` closes resources even if the block raises. File mode `w` truncates, `a` appends, `x` creates only if absent, `rb` reads bytes. `Path.mkdir(parents=True, exist_ok=True)` creates directories. Use `csv.reader`/`DictReader` with `newline=''` for CSV. [Exceptions](https://docs.python.org/3/tutorial/errors.html), [I/O](https://docs.python.org/3/tutorial/inputoutput.html).

## 9. Standard-library toolkit and program structure

| Need | Tool |
| --- | --- |
| Frequencies / grouped lists | `collections.Counter`, `defaultdict(list)` |
| Queue | `collections.deque`, `append`, `popleft` |
| Iterator operations | `itertools.chain`, `islice`, `product`, `combinations` |
| Cached pure computation | `functools.lru_cache` |
| Paths / CLI / logs | `pathlib`, `argparse`, `logging` |
| Dates / elapsed time | `datetime` with aware times; `time.perf_counter()` |
| Regex | `re.search`, `re.fullmatch`, `re.sub`; use raw patterns |
| Debugging / timing | `breakpoint()`, `traceback`, `timeit`, `cProfile` |
| Async I/O / processes | `asyncio`; `concurrent.futures.ProcessPoolExecutor` |

```python
from collections import Counter, defaultdict
from functools import lru_cache

assert Counter('banana')['a'] == 3
groups = defaultdict(list)
groups['train'].append(1)

@lru_cache(maxsize=128)
def square(n):
    return n * n

def main():
    print(square(4))

if __name__ == '__main__':
    main()
```

Import modules with `import package.module` or `from package import name`; avoid wildcard imports and filenames such as `numpy.py` that shadow libraries. The main guard matters for multiprocessing on Windows. Threads suit blocking I/O; CPU speedups depend on the runtime and whether code releases the GIL. Async functions produce coroutines that must be awaited or scheduled.

## 10. Common mistakes

| Symptom | Check |
| --- | --- |
| Unexpected shared changes | Assignment aliases; shallow copies share nested values |
| A list becomes `None` | `sort`, `append`, `extend` mutate and return `None` |
| State leaks between calls | Mutable default argument |
| Wrong equality | Use `==` for values and `is None` for the sentinel |
| Missing final item | Slice/range stop is exclusive |
| Import error | Interpreter, environment, package name, shadowing file |
| Input validation disappears | `assert` may be disabled; raise an exception for validation |
| Slow membership checks | Sets/dicts generally beat lists for repeated hashable lookups |

Further reference: [built-ins](https://docs.python.org/3/library/functions.html), [standard library](https://docs.python.org/3/library/), [language reference](https://docs.python.org/3/reference/).
