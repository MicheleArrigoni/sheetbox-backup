## 1. Figure, Axes, and Axis

A `Figure` is the complete canvas; an `Axes` is one plotting area; its `Axis` objects manage scales and ticks. Prefer explicit `fig`/`ax` references when composing plots. [Quick start](https://matplotlib.org/stable/users/explain/quick_start.html).

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)
x = np.linspace(0, 2 * np.pi, 200)
y = np.sin(x)
fig, ax = plt.subplots(figsize=(7, 4), layout='constrained')
ax.plot(x, y, label='sin(x)', color='C0', linewidth=2)
ax.set(xlabel='Angle [rad]', ylabel='Amplitude', title='Sine wave')
ax.grid(True, alpha=0.3)
ax.legend(loc='best')
fig.savefig('sine.png', dpi=180, bbox_inches='tight')
plt.close(fig)
```

Use `plt.show()` for display in an interactive session. Save before a blocking `show()` if the window may close; keep a `fig` reference. `figsize` is in inches; raster pixel size is approximately inches × DPI. Close figures in loops to release resources.

## 2. Choose the plot

| Data / purpose | Axes method | Important arguments |
| --- | --- | --- |
| Ordered observations | `plot(x, y)` | `color`, `linestyle`, `marker`, `linewidth`, `label` |
| Independent points | `scatter(x, y)` | `s` area in points squared, `c`, `cmap`, `alpha` |
| Categories | `bar(labels, heights)`, `barh` | `width`, `yerr`, `bottom` |
| Distribution | `hist(data)` | `bins`, `range`, `density`, `histtype` |
| Distribution comparison | `boxplot(groups)`, `violinplot(groups)` | orientation, positions |
| Uncertainty | `errorbar(x, y, yerr=...)` | `fmt`, `capsize`, `xerr` |
| Band | `fill_between(x, low, high)` | `alpha`, `where` |
| Regular pixel grid | `imshow(Z)` | `origin`, `extent`, `aspect`, `interpolation` |
| Cell grid / irregular spacing | `pcolormesh(X, Y, Z)` | `shading`, `cmap`, `norm` |
| Level curves / filled regions | `contour`, `contourf` | `levels`, `cmap` |
| Vector field | `quiver`, `streamplot` | vector components, scale |
| Dense point cloud | `hexbin`, `hist2d` | bin resolution, colormap |

[Plot gallery and signatures](https://matplotlib.org/stable/plot_types/index.html).

## 3. Lines, scatter, histograms, and uncertainty

```python
fig, axs = plt.subplots(2, 2, figsize=(10, 7), layout='constrained')
axs[0, 0].plot(x, np.sin(x), color='C0', linestyle='--', label='sin')
axs[0, 0].plot(x, np.cos(x), color='C1', label='cos')
axs[0, 0].legend()
points = rng.normal(size=(150, 2))
sc = axs[0, 1].scatter(points[:, 0], points[:, 1],
                     c=np.linalg.norm(points, axis=1), s=15, cmap='viridis')
fig.colorbar(sc, ax=axs[0, 1], label='Distance')
axs[1, 0].hist(rng.normal(size=1000), bins=30, density=True,
               color='C2', edgecolor='white')
t = np.linspace(0, 1, 12)
mean = 2 * t
sigma = np.full_like(t, 0.15)
axs[1, 1].errorbar(t, mean, yerr=sigma, fmt='o', capsize=3)
axs[1, 1].fill_between(t, mean - sigma, mean + sigma, alpha=0.2)
for axis in axs.flat:
    axis.grid(True, alpha=0.2)
plt.close(fig)
```

`density=True` normalizes histogram area to 1, not the sum of bar heights. For asymmetric errors, pass nonnegative error magnitudes with shape `(2, N)`; row 0 is lower, row 1 upper. State whether bands indicate standard deviation, standard error, or a confidence interval. Lines connect observations in input order: sort paired x/y data together when needed.

## 4. Subplots and layouts

```python
fig, axs = plt.subplots(2, 3, squeeze=False, sharex=True, sharey=True,
                        figsize=(10, 5), layout='constrained')
for i, axis in enumerate(axs.flat):
    axis.plot(x, np.sin(x + i / 2))
    axis.set_title(f'Panel {i + 1}')
fig.supxlabel('Angle [rad]')
fig.supylabel('Amplitude')
fig.suptitle('Shared axes')
plt.close(fig)

fig, axes = plt.subplot_mosaic([['main', 'side'], ['main', 'bottom']],
                                layout='constrained')
axes['main'].plot(x, y)
plt.close(fig)
```

With default `squeeze=True`, `subplots()` returns one Axes for 1×1, a 1D array for a single row/column, and a 2D array otherwise. `squeeze=False` always returns a 2D array. Prefer one layout engine; do not combine `tight_layout()` with constrained layout. [Layout guide](https://matplotlib.org/stable/users/explain/axes/constrainedlayout_guide.html).

## 5. Labels, ticks, limits, scales, and annotation

```python
from matplotlib.ticker import MultipleLocator, FuncFormatter

fig, ax = plt.subplots(layout='constrained')
ax.plot(x, y, label=r'$\sin(x)$')
ax.set_xlim(0, 2 * np.pi)
ax.set_ylim(-1.3, 1.3)
ax.xaxis.set_major_locator(MultipleLocator(np.pi / 2))
ax.xaxis.set_major_formatter(FuncFormatter(lambda v, pos: f'{v / np.pi:g}π'))
ax.tick_params(axis='both', labelsize=10)
ax.axhline(0, color='0.5', linewidth=0.8)
ax.annotate('maximum', xy=(np.pi / 2, 1), xytext=(3, 1.15),
            arrowprops={'arrowstyle': '->'})
ax.text(0.02, 0.95, 'A', transform=ax.transAxes, va='top')
ax.legend()
plt.close(fig)
```

`ax.transAxes` uses 0–1 relative panel coordinates; default text coordinates are data coordinates. Set tick positions and labels together with `ax.set_xticks(positions, labels=labels)`; avoid assigning labels without fixed positions. `ax.set_aspect('equal')` makes equal data increments occupy equal lengths.

For positive data use `ax.set_xscale('log')` / `set_yscale('log')`, or `semilogx`, `semilogy`, `loglog`. A logarithmic scale cannot represent zero or negative values; consider `symlog` with an explicit `linthresh` where appropriate. [Axis scales](https://matplotlib.org/stable/users/explain/axes/axes_scales.html).

## 6. Images, heatmaps, contours, and colorbars

```python
gx = np.linspace(-2, 2, 80)
gy = np.linspace(-1, 1, 40)
X, Y = np.meshgrid(gx, gy, indexing='xy')
Z = np.exp(-(X**2 + Y**2))          # (len(gy), len(gx))
fig, axs = plt.subplots(1, 2, figsize=(9, 3.5), layout='constrained')
im = axs[0].imshow(Z, origin='lower', aspect='auto', cmap='viridis')
axs[0].set(xlabel='Column index', ylabel='Row index')
fig.colorbar(im, ax=axs[0], label='Value')
field = axs[1].contourf(X, Y, Z, levels=np.linspace(0, 1, 11), cmap='viridis')
axs[1].set(xlabel='x', ylabel='y')
fig.colorbar(field, ax=axs[1], label='Value')
plt.close(fig)
```

`imshow` maps array rows to y and columns to x. Its default origin is upper; `origin='lower'` puts row 0 at the bottom. `extent=(left, right, bottom, top)` specifies outer image edges, not sample centers. For irregular spacing prefer `pcolormesh`; use explicit cell edges or `shading='auto'` with suitable coordinates.

Use a perceptually ordered colormap such as `viridis` for magnitude; a diverging map centered at a meaningful reference for signed deviations. Share the same normalization across panels intended for quantitative color comparison.

```python
from matplotlib.colors import Normalize, TwoSlopeNorm, LogNorm
linear_norm = Normalize(vmin=0, vmax=1)
signed_norm = TwoSlopeNorm(vmin=-2, vcenter=0, vmax=3)
positive_norm = LogNorm(vmin=0.01, vmax=100)
# Pass norm=... to imshow/scatter/pcolormesh; omit separate vmin/vmax.
```

[Colormap normalization](https://matplotlib.org/stable/users/explain/colors/colormapnorms.html).

## 7. 3D surfaces and dates

```python
fig = plt.figure(figsize=(6, 4), layout='constrained')
ax = fig.add_subplot(projection='3d')
surface = ax.plot_surface(X, Y, Z, cmap='viridis')
ax.set(xlabel='x', ylabel='y', zlabel='Value')
fig.colorbar(surface, ax=ax, shrink=0.7)
plt.close(fig)

from datetime import datetime, timedelta
import matplotlib.dates as mdates
dates = [datetime(2026, 1, 1) + timedelta(days=i) for i in range(10)]
fig, ax = plt.subplots(layout='constrained')
ax.plot(dates, np.arange(10))
locator = mdates.AutoDateLocator()
ax.xaxis.set_major_locator(locator)
ax.xaxis.set_major_formatter(mdates.ConciseDateFormatter(locator))
plt.close(fig)
```

For 3D, coordinate arrays and heights must have compatible 2D shapes; use contours or heatmaps when exact comparisons matter. Use timezone-aware dates when absolute time matters.

## 8. Styling, export, and animation

```python
with plt.rc_context({'font.size': 11, 'axes.spines.top': False,
                     'axes.spines.right': False}):
    fig, ax = plt.subplots(figsize=(6, 3), layout='constrained')
    ax.plot(x, y, color='#0072B2', label='Signal')
    ax.legend()
    fig.savefig('signal.svg', bbox_inches='tight')
    fig.savefig('signal.png', dpi=200, transparent=True, bbox_inches='tight')
    plt.close(fig)
```

PNG is raster; SVG/PDF preserve vector paths and text where possible. Use `rasterized=True` on very dense artists in vector outputs. Add units, readable font sizes, and accessible color/line distinctions. `rc_context` limits style changes to its block.

For headless scripts, select a noninteractive backend before importing pyplot: `import matplotlib; matplotlib.use('Agg')`. For animation, use `matplotlib.animation.FuncAnimation`, keep the returned animation in a variable, and return modified artists when `blit=True`; exporting video also requires an available writer. [Animation](https://matplotlib.org/stable/api/animation_api.html).

## 9. Troubleshooting

| Problem | Check |
| --- | --- |
| Blank exported image | Save the intended `fig`, before closing it |
| Shape mismatch | `x` and `y` lengths; grid shape `(ny, nx)` |
| Twisted line | Input order; sort x and matching y together |
| Upside-down heatmap | `origin`, row order, coordinate convention |
| Different colors imply same value | Use shared `norm`, colormap, and colorbar units |
| Labels overlap | Figure size and constrained layout |
| Missing legend entries | Set `label` on artists before `legend()` |
| Memory grows | Close figures; avoid retaining large artists unnecessarily |
| No window | Backend and event loop; headless environments need file export |

Full reference: [Axes API](https://matplotlib.org/stable/api/axes_api.html), [pyplot API](https://matplotlib.org/stable/api/pyplot_summary.html).
